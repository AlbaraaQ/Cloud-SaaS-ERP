# 01 — الوضع الحالي قبل إعادة التنظيم (Current State)

> لقطة تشخيصية لما كان عليه المستودع عند بداية العمل (سبتمبر 2026)، قبل أي تعديل.
> الأرقام والمسارات هنا تاريخية — البنية المستهدفة في `02-target-architecture.md`.

## 1. الأسطح (قبل)

| التطبيق | النطاق المقصود | الواقع |
|---|---|---|
| `apps/admin` | لوحة الموظفين + لوحة المنصة معاً | تطبيق واحد يخدم سطحين: كل شاشات ERP (`/accounting…`) **ولوحة المنصة** (`/platform/*`)، مع تسجيل ذاتي (`SignupPanel`) داخل شاشة الدخول |
| `apps/customer` | موقع تسويقي + بوابة عملاء معاً | تطبيق واحد يخدم سطحين: صفحات عامة (`/`، `/pricing`، `/verify`…) **وشاشات البوابة المصادق عليها** (`/portal/*`، `/auth/*`) |

النتيجة: أربعة أسطح منطقية مكدّسة في نشرتين (deployments) فقط، ولا يمكن نشر أي سطح باستقلال.

## 2. RBAC (قبل)

- `users.is_platform_admin` عمود boolean واحد يمنح **كل شيء**: قراءة/كتابة كل المنشآت، إدارة الباقات والتراخيص، إدارة المستخدمين عبر المنشآت.
- لا توجد أدوار منصة (Family A غير موجودة): المشغّل إما مدير مطلق أو لا شيء.
- لا توجد عضويات منصة (`platform_memberships` غير موجودة).
- أذونات المنشأة تحت بادئة `platform.*` الملتبسة (`platform.tenant.view`، `platform.users.manage`…) رغم أنها أذونات **مستأجر** لا منصة.
- الأجهزة (`devices`) مرتبطة بالمستخدم/الكاشير بدل كيان مستقل.
- `memberships` بلا `kind`: لا تمييز بين موظف ومشترٍ (buyer) و API.

## 3. الحمايات (قبل)

- `PlatformGuard` في تطبيق الإدارة يعتمد على `isPlatformAdmin` من `/me`.
- `tenant_owner` (`isOwner`) يمنح `'*'` داخل المنشأة — صحيح النطاق لكنه أعمى وظيفياً.

## 4. مشاكل مؤكدة شخّصناها

1. **التباس `platform.*`**: نفس البادئة تعني أحياناً "صلاحية مشغّل المنصة" وأحياناً "صلاحية مدير المنشأة".
2. **زر التفعيل المكسور**: صفحة الأسعار العامة تستدعي `POST /billing/activation-requests` (مصادق عليه) بلا جلسة → `401` دائم.
3. **صفحة تواصل صورية**: نموذج بزر لا يفعل شيئاً (لا API خلفه).
4. **معالج التهيئة صوري**: زر "بدء التهيئة" بلا أي استدعاء.
5. **رابط ميت في التنقل**: شاشة `user-logs` تشير إلى `/platform/audit` المحجوب عن المستأجرين.
6. **التسجيل في المكان الخطأ**: إنشاء المنشآت متاح من داخل وحدة تحكم مصادق عليها بدل الموقع العام.
7. **`localStorage` يتطلب `refreshToken`**: أي جلسة بلا تحديث تُرفض صامتة (أثّر على تصميم جسر الجلسات).
