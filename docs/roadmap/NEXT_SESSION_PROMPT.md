## 1. ✂️ ابدأ النسخ من هنا

```
أنت وكيل يعمل على مستودع Cloud-SaaS-ERP (ERP سحابي متعدد المستأجرين: NestJS API +
Next.js لأسطح staff وplatform-admin وmarketing وcustomer-portal + PostgreSQL مع RLS).
الواجهة عربية أولاً (RTL)، والتواصل معي بالعربية.

══════════════════════════════════════════════════════════════════════════════
1) اقرأ أولاً (لا تبدأ بالكود قبلها):
   - docs/roadmap/README.md            ← نقطة الدخول: البيئة، القيود، بوابات «تم»، أرقام اليوم
   - docs/roadmap/INCOMPLETE_INVENTORY.md  ← كل ما لم يكتمل (مقيس)
   - docs/roadmap/AUDIT_PHASES_01_04.md    ← إن كان عملك في المراحل 1–4
   - docs/roadmap/PLATFORM_CONSOLE_PLAN.md ← إن كان عملك في لوحة المنصة
   - docs/roadmap/MARKETING_SITE_PLAN.md   ← إن كان عملك في الموقع التسويقي
   ثم افتح القسم الخاص بالجزء المطلوب واقرأه كاملاً قبل أن تكتب سطراً.

2) ابدأ بالجزء: P-C1 — «الأساس والقشرة، وترميم الصلاحيات» من
   docs/roadmap/PLATFORM_CONSOLE_PLAN.md §4 (الأولوية 🔴، وكل ما بعده يعتمد عليه).
   نفّذه وحده في هذه الجلسة، ولا تتجاوزه إلى P-C2 إلا بعد أن يصير أخضر.

3) هيّئ البيئة بهذا الترتيب (التفاصيل في docs/roadmap/README.md §2):
   corepack enable && pnpm install --no-frozen-lockfile
   pnpm -r --filter "./packages/*" build
   pnpm db:local && pnpm db:migrate && pnpm db:seed
   pnpm dev        # API :3000 · staff :3001 · marketing :3002 · platform :3003 · portal :3004
   لا تحاول تثبيت Docker أو Postgres في بيئة العمل. الخوادم تُشغَّل بأداة العمليات
   (start_process) لا بـ nohup. لا تشغّل next build وخادم Next يعمل (تعارض معروف).
   الحسابات: owner@demo.test على المستأجر demo، وكلمات المرور في .env.

4) قيود ثابتة من صاحب المشروع — لا تُخالف:
   أ. العربية أولاً في الواجهة وفي التواصل.
   ب. كل شاشة تنقلها من النسخة المكتبية تسمّي ملفها من Desktop_ERP نصّاً برقم سطره،
      وتسمياتها العربية تُؤخذ بالحرف (نسبة تطابق ≥ 90٪)، وأي تسمية مخترَعة تُبرَّر
      صراحةً في جدول «ما اخترعناه» وفي تقريرك النهائي.
   ج. لا `git add -A` أبداً: تُدرَج المسارات صراحةً، ثم
      `git status --short | grep -v '^??'` للتأكد، ثم فحص
      `gh api repos/AlbaraaQ/Cloud-SaaS-ERP/pulls/4/files` أن لا شيء من apps/admin*
      أو apps/customer* دخل في الطلب.
   د. كل شاشة جديدة طريقٌ حقيقي: apps/staff/tests/navigation.spec.ts يثبت أن كل بند
      ready له صفحة موجودة.
   هـ. 🇪🇬 مصر (frmEtaSetting · EtaService · EtaReciptService) ونداءا 🚫 إلغاء الفاتورة
      و❌ رفض الفاتورة: خارج النطاق بقرار صريح — النظام موجّه للسعودية (زاتكا).
      تُسجَّل «مؤجَّلة/خارج النطاق» في الوثائق ولا تُحذف.
   و. اعمل على فرع جلستك أنت، ولا تبدّل إلى فرع آخر. مرجع الحالة: الدفعتان الأخيرتان
      a5c998d (المرحلة 11 — الجزء السادس 📱 واتساب) و cba80ae (وثائق خريطة العمل).

5) تعريف «تم» للجزء (بوابات المراحل 5–11، مفصّلة في docs/roadmap/README.md §4):
   1. مصدرٌ مسمّى بالسطر (ملفات Desktop_ERP إن كانت مطابقة، وإلا ملفات هذا المستودع
      والمواصفة المنشورة للخدمة).
   2. تسميات بالنص + تبرير المخترَع.
   3. نقطة نهاية حقيقية تعمل + مهايئ خدمة حقيقي + مفتاح 🧪 محاكاة (لا محاكاة في وقت التشغيل،
      ولا شبكة خارجية في الاختبارات).
   4. ترحيل مرقَّم + مخطط Drizzle + RLS بـ ENABLE و FORCE وسياسة tenant_id.
   5. صلاحيات من السجل القائم؛ والرمز الجديد يحتاج ثلاثة أشياء معاً: إعلاناً في
      packages/contracts/src/permissions.ts، وإدراجاً idempotent في الترحيل، واختبار
      apps/api/src/permission-codes.spec.ts.
   6. ملف اختبار API جديد + سكربت تحقّق حيّ في scripts/verify-*.mjs قابل لإعادة التشغيل
      (يصوّر الحالة ويعيدها، ولا يُرسل بريداً ولا رسالة حقيقية).
   7. شاشة حقيقية في الشجرة بحالة ready + بناء Next أخضر.
   8. الوثائق: وثيقة الجزء + تحديث docs/STATUS.md + README الوحدة.
   9. دفعة بمسارات صريحة + تعليق عربي واحد على PR #4 بالأرقام وبجدول «الديسكتوب ← السحابة».

6) قبل أن تردّ عليّ أخيراً، أعد تشغيل: اختبارات API كاملة، واختبارات staff،
   واختبارات contracts، وtsc وeslint، وبناء كل تطبيق مسّسته — وأعطني الأرقام قبل وبعد
   (API كان 951 · staff 36 · contracts 71 · ترحيلات حتى 0065).

7) بلّغني في النهاية: ما الذي بُني (ملفات)، ما الذي لم يُبنَ ولماذا، الأرقام قبل/بعد،
   الترحيل الجديد، الشاشة وطريقها، وعدد نقاط سكربت التحقّق الحيّ وعدد تشغيلاته الخضراء،
   ثم التسميات المخترَعة مع تبرير كل واحدة.
```
