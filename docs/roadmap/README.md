## 2. تهيئة البيئة (بنفس الترتيب)

```bash
corepack enable                      # لا pnpm بلا corepack في هذه البيئة
pnpm install --no-frozen-lockfile
pnpm -r --filter "./packages/*" build   # إلزامي قبل أي أمر يعتمد على الحزم
pnpm db:local                        # PostgreSQL مضمّن (لا docker ولا psql هنا)
pnpm db:migrate                      # حتى 0065
pnpm db:seed                         # من apps/api
pnpm dev                             # API :3000 · staff :3001 · portal :3002 · platform :3003 · marketing :3004
```

- الخوادم تُشغَّل بأداة العمليات (`start_process`) لا بـ `nohup`؛ واجهات Next على `0.0.0.0`.
- **لا تحاول تثبيت Docker أو Postgres** في بيئة العمل؛ التشغيل الحقيقي عند المستخدم عبر
  `infrastructure/docker-compose.yml` (فيه: postgres · redis · minio · mailhog).
- **لا تشغّل `next build` وخادم Next يعمل** — تعارض معروف؛ التعافي بحذف `.next`.
- الحسابات: `owner@demo.test` على المستأجر `demo`، وكلمات المرور في `.env`
  (`DEMO_OWNER_PASSWORD` · `DEMO_ACCOUNTANT_PASSWORD` · `DEMO_CASHIER_PASSWORD` ·
  `PLATFORM_ADMIN_EMAIL`).
